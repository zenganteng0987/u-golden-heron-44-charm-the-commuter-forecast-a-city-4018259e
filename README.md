Charm the Commuter: Forecast a City That Isn't — a one-line weather forecast
(120 characters) for a city that does not exist.

## Entry

> Good morning, Nibblewick: cloudy, 16°C, with a 90% chance of pigeons stealing your sandwich before the 8:15 bus arrives.

## Run

```sh
node main.ts
```

The program writes the single forecast line to `/output/entry.txt`
(`OUTPUT_PATH` overrides the output path for local testing).
